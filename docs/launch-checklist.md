# Launch checklist

Before opening the store to shoppers:

- [ ] Replace the eight demo product rows with verified products, prices, descriptions, stock and approved images.
- [ ] Run the Supabase migration, add Vercel public env values and verify browse/order/tracking in a staging project.
- [ ] Connect the repository to Vercel and confirm a push to `main` deploys successfully.
- [ ] Add a payment gateway in a separate approved phase; this build intentionally has no payment collection.
- [ ] Set real delivery coverage, charges, timing, returns/refunds, warranty and contact information.
- [ ] Publish a privacy notice and retention/deletion process for delivery information.
- [ ] Add anti-abuse/rate limits and monitor public order-creation calls.
- [ ] Check mobile layouts, product photos, metadata, sitemap and custom domain.
- [ ] Review applicable consumer, product-safety, privacy and tax obligations before launch.
